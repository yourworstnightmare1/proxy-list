# Filter Data
The Proxy List allows you to know exactly what known filters block websites, with summaries powered by the gn-math Discord bot, covering 20+ web blocking filters with data on most blocked domains, block reasons, and total blocked/unblocked, with the ability to filter sites shown by only the ones unblocked by a specified filter.

# Game Databases
View info on game databases contained in these unblocked games websites using the Game Browser, where you can view games, diffs on the database, and links using that database.

# Site Tagging
Easily find what you need on the list with tags going with each link, defining their exact purpose and featureset, along with filtering between site categories, capabilities, and proxy protocols.

# Advanced Customization
Customize the list to your exact needs with detailed settings on things in the list, such as time/date customization, performance and optimization, developer tools, and more.

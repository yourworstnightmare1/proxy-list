How was the Proxy List created?

It was created around October 2025 and started as a non-public Google Doc, where links would be added nearly every day that were all confirmed to be unblocked locally, and was shared with others I knew. It lasted until December 4th, 2025 where the list was given to the wrong people and had to be deleted to prevent getting into trouble. A v2 of the doc was made shortly after with a new URL and links but was scrapped after I realized that Google Docs simply were no longer sufficient for what I and others needed. On February 19, 2026, I created the Proxy List, which started out as a simple .md file with a list of over 100+ links I gathered, new and old from previous docs I made. It grew much larger much more quick and I found that the markdown was cluttered and it was hard to find links that actually worked since there was so many, so I decided to make it into a website where you can sort links and check if a link is blocked, which is what you're viewing this text on now.

How many links are currently here?

There is currently — sorted links here, with — unsorted links also available. Nearly all sorted links also have filter data, so you'll know what's blocked and what's not without having to go on individual sites and checking.

How often is this list updated?

The list has new links usually every week, and is auto-maintained by a bot that checks every link every 8 hours to ensure no broken or dead links remain in the list. Filter data is also updated every week manually by me using a macro, which checks every link existing in the list for data, then gets auto-uploaded to GitHub, where it is then pushed and seen by the public.

Can I create copies of this site?

Yes, you can create copies and mirrors of this site on whatever domain you please, and all of the list's source code is available on GitHub so you have a near exact version of the list with the auto-check bot included.

How can I add sites?

You can add links or sections by either going on GitHub and making a pull request with your desired links, or going to the Contribute page on the Proxy List site and filling out the form.

Contribution rules

Short checklist from the project contribution guide.

  1. Do not submit links that already exist in the list.
  2. Links must be working and active when submitted.
  3. Keep formatting consistent with list.md table structure.
  4. For locked links, include valid username/password or do not submit them.
  5. Give a contributor name/alias so credit can be assigned.

How to contribute

  1. Sign in and use the submission form below for quick review.
  2. Use GitHub for direct edits and pull requests.
  3. For GitHub, add rows in the existing table format under the right section.
  4. If you add a new section, include emoji + note table + links table.

Categories and capabilities are assigned during review — you only need the URL and provider.

Submit links for review

Submit one or more working proxy URLs under an existing provider or propose a new one. Duplicate URLs (including ones already on the list) are rejected. We compare full URLs, not whole domains, so multiple proxies on the same domain with different paths or subdomains are allowed.

What you get with an account

Anonymous browsing still works without signing in. Every signed-in account gets the core tools below.

  • Saved links Star links from the list and reopen them from your profile on any device.
  • Saved filters and settings Keep your web filter, sort mode, and sidebar choices tied to your account.
  • Personal greeting See a time-of-day hello with your display name or email when you return.
  • Contributor highlights GitHub sign-in only: YOU badge when your GitHub login matches the contributor field.
  • Repo activity GitHub sign-in only: pull request and issue updates for this list in the header.
  • Star recognition GitHub sign-in only: gold username in the header when you star the proxy-list repo.
